## Download

Die Installationsdateien liegen unter [**Releases**](../../releases/latest) (eine Datei pro System):

| System | Datei |
| :--- | :--- |
| **Windows** | `Naturschule.Chat.msi` |
| **macOS** | `Naturschule.Chat.dmg` |
| **Linux** | `naturschule-chat.AppImage` |

Eine kurze Hilfe zur Installation gibt es hier: [**Eltern-Anleitung (PDF)**](docs/eltern-anleitung.pdf).

## Hinweise

- **Ein Fenster:** Verhindert doppelte App-Fenster.
- **Hintergrundbetrieb:** Läuft beim Schließen über die Symbolleiste weiter, damit Nachrichten ankommen.
- **Links:** Externe Links öffnen im Standardbrowser.
